START HERE — work safely with your community website

You do not need to understand React, TypeScript, Vite, Git, or terminal commands to use this starter.

1. Install Node.js LTS once. Go to https://nodejs.org/ and choose the LTS download.
2. Keep one untouched approved copy of this whole project folder.
3. Make a separate candidate copy before every change.
4. In the candidate, double-click START-WEBSITE.bat. A browser preview opens. Closing the command window stops it.
5. Double-click MAKE-AI-COPY.bat. It creates AI-COPY\recovery-dharma-atlantis-source.zip.
6. Attach that ZIP, AI_READ_FIRST.txt, MY_WEBSITE_FACTS.txt, and CHANGE_REQUEST.txt to an AI tool that accepts files.
7. Ask for a complete updated project ZIP, or every complete changed file if it cannot make a ZIP.
8. Extract the returned candidate separately. Do not overwrite your approved copy.
9. Double-click START-WEBSITE.bat in the returned candidate.
10. Inspect Home, Meetings, About, New Here, Resources, Connect, mobile navigation, and a deliberately mistyped page address.
11. Correct it, approve it, or delete it. Keep only versions you have personally inspected.
12. Publish only a version you personally inspected. For manual hosting, run BUILD-WEBSITE.bat and upload the contents of PUBLISH-THIS-FOLDER.

WHAT YOU CAN SAFELY ASK AN AI TO CHANGE

- Community wording in src/content/.
- The two structured recurring meetings in src/content/meetings.ts.
- A one-time meeting through the existing configuration in src/content/announcements.ts.
- Colour, typography, and spacing tokens in src/styles/tokens.css while preserving DESIGN_GUIDE.md, route compositions, and meeting rules.
- Resource links only after you have verified them.

Important: this untouched starter is fictional. It is not a real meeting listing. Do not remove the fictional label, footer notice, indexing block, or fictional mode until every public fact has been verified and you knowingly decide to convert it.

ADVANCED TROUBLESHOOTING

The batch files are the normal path. A technical helper can run npm ci, npm run dev, and npm run verify from this folder if they need to diagnose a problem.
